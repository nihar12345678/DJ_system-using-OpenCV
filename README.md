# DJ_system-using-OpenCV

With advancements in human-computer
interaction, gesture recognition has
emerged as a natural and intuitive way
to control systems. This project uses
computer vision and the OpenCV library
to track hand movements in real time
through a webcam. These gestures are
mapped to audio controls such as
volume, bass, treble, and vocals,
eliminating the need for traditional input
devices like keyboards or mixers.
